# Carla López Vila — Portfolio

Live site: https://carlalovi.github.io

## How to edit

All texts, projects and their order live in **`content.js`**. The instructions are at the top of that file.

- **Add a project:** copy a `{ ... }` block in `projects`, change `id`, texts and paths, and put its files in `media/<id>/`.
- **Hide a project:** add `hidden: true,` to its block.
- **Reorder:** move the blocks.

To publish a change: edit the file on GitHub (pencil icon) and click *Commit changes*. The site updates in about a minute.

Recommended formats: images in `.webp` or `.jpg` (≤ 2000 px), videos `.mp4` H.264 (≤ 20 MB), 3D models `.glb`.
